## DBMS Capstone Project

### ShadowTrace – Digital Investigation & Evidence Management System

ShadowTrace is a web-based system designed to manage digital investigation cases and organize digital evidence records.

**Technology Stack:**
- **Frontend:** HTML5, CSS3, Bootstrap, Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL (Neon)
- **Authentication & Security:** Express Sessions, connect-pg-simple, bcryptjs
- **Database Connectivity:** pg (node-postgres)
- **Deployment:** Render
